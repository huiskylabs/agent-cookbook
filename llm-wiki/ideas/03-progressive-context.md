# Progressive Context

## Universal Idea

A system should reveal the right context at the right time, not all context at once.

A large knowledge system becomes less useful if every task starts by loading everything. Good memory starts broad, then narrows.

```text
task
  -> broad context
  -> relevant context
  -> answer or act
  -> go deeper only when needed
```

The universal idea is progressive context: reveal enough to orient the work, then reveal more only when the task needs it.

## Why It Matters

More context is not automatically better context.

Too much context can bury the actual task, increase cost, and make the system behave unpredictably. Progressive context keeps memory useful by making context staged.
